# Calcolo Letterale — Matematica

**Sito pubblico:** https://ventilii-gif.github.io/letterale-1/

Web app didattica (HTML singolo) per imparare il calcolo letterale:

- **Monomi** — somma e differenza, prodotto e divisione, potenze
- **Monomio × Polinomio** — proprietà distributiva
- **Polinomio × Polinomio** — ogni termine per ogni termine
- **Prodotti notevoli** — differenza di quadrati, quadrato del binomio e del trinomio, somma e differenza di cubi
- **Divisione tra polinomi** — divisione lunga, regola di Ruffini, regola del resto

Ogni sezione contiene: teoria essenziale, una **simulazione animata passo-passo**,
esercizi svolti e un **mini-quiz** interattivo. La pagina iniziale presenta il
percorso con una nota storica sull'algebra.

Pubblicata tramite GitHub Pages dal branch `main` (repository `ventilii-gif/letterale-1`).
