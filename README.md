# Calcolo Letterale — Matematica

Web app didattica (HTML singolo) per imparare il calcolo letterale:
monomi (somma/differenza, prodotto/divisione, potenze), prodotti monomio×polinomio
e polinomio×polinomio, prodotti notevoli (differenza di quadrati, quadrati di binomi
e trinomi, somma/differenza di cubi) e divisione tra polinomi (divisione lunga,
regola di Ruffini, regola del resto).

Ogni sezione contiene: teoria essenziale, una simulazione animata passo-passo,
esercizi svolti e un mini-quiz interattivo.

Pubblicata su GitHub Pages.
